# PerryBox 人工测试用例

用于验证 2026-08 重构（页面拆分 + 逻辑纯函数化 + CRC 数据驱动 + 防崩溃修复）后功能无回归。

- 被测对象：`build\debug\PerryBox.exe`（由 `build_run.bat` 构建并启动）
- 测试方法：按下表逐条操作，在"实际结果"列记录（通过打 ✓，失败写现象）
- 约定：
  - "红字提示"指页面下方红色 `label_info_*` 标签文字
  - 时间戳页"本地时间"预期值按 **UTC+8** 计算，其他时区需自行换算
  - 正则编译错误的报错文本来自标准库（英文），只需确认有红字提示且程序不崩溃

## 已知行为说明（非 bug，无需提单）

1. ASCII 页切换前缀勾选时，以 **ASCII 输入框当前内容**为源重新转换（重构前一致）。
2. 进制输入混用前缀（如 `0x31 31`）视为非法（重构前一致）。
3. CRC 计算结果统一大写、带前导零；输入大小写均可。
4. 正则编译错误文案为标准库英文描述，仅要求"有红字、不崩溃"。
